# 小红爪子 - 小红书数据统计工具
相信做小红书投放的同学，在面临总结时都遇到过手动统计互动数的绝望时刻。自己手工统计任务繁重，博主主动提交数据又往往有很长的周期，尤其碰到一些高密传播周期的时候，想要及时的反馈又面临人力上的捉襟见肘，这时候就想着：要是有一键就库库整完数据就好了！
翻了一下现下确实有一些可使用的工具，但大多都要收费，于是就用vibe coding开发了这个小插件，它可以让大家用相对轻巧的方式一键获取笔记的转评赞，并汇总成excel表格。
这个插件只需要你有chrome浏览器和小红书账号就可以免费使用。

## 功能特点

- 批量分析小红书链接
- 提取博主名字、标题、评论数、点赞数、收藏数
- 将结果导出为 Excel 文件

## 安装方法

1. 下载（可以直接下载redclaw2025.zip）或克隆本项目到本地计算机
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 打开右上角的"开发者模式"
4. 点击"加载未打包的扩展程序"
5. 选择本项目所在的文件夹
6. 插件安装完成

## 使用方法
1. 在chrome网页端登陆你的小红书账号，很重要，不然数据会简略，变成类似10+，1千+之类的
2. 点击扩展图标，在弹窗中粘贴小红书链接（一次性不要太多，建议100条以内，不然小红书容易判断用户行为异常，退出登录）
3. 点击"开始分析"按钮等待分析完成*分析过程中不可以关闭“小红爪子”的界面，关掉就停止分析了。
4. 点击"导出Excel"按钮保存结果

## 数据字段说明

- **url**: 小红书笔记的完整链接
- **author**: 发布该笔记的博主用户名
- **tittle**: 笔记的标题
- **coments**: 该笔记收到的评论数量
- **likes**: 该笔记收到的点赞数量
- **collets**: 该笔记被收藏的数量

## 注意事项

- 由于小红书网站的反爬虫机制，可能部分链接无法获取数据.
- 如果遇到获取失败的情况，请稍后再试
- 建议用小号登录小红书，我目前备退出后再次登录就可以正常使用，但不清楚会不会被后台打标影响发布内容流量之类的……
- 请遵守网站的使用条款，不要过于频繁地请求数据
