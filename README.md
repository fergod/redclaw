# 小红爪子 - 小红书数据统计工具

这是一个 Chrome 浏览器插件，可以帮助你批量统计小红书链接的博主信息、标题、评论数、点赞数和收藏数，并将结果导出为 Excel 文件。

## 功能特点

- 批量分析小红书链接
- 提取博主名字、标题、评论数、点赞数、收藏数
- 将结果导出为 Excel 文件

## 安装方法

1. 下载或克隆本项目到本地计算机
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 打开右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目所在的文件夹
6. 插件安装完成

## 使用方法

1. 点击浏览器工具栏中的"小红爪子"图标
2. 在文本框中粘贴小红书链接，每行一个
3. 点击"开始分析"按钮
4. 等待分析完成后，点击"导出Excel"按钮
5. 保存生成的 Excel 文件

## 数据字段说明

- **链接**: 小红书笔记的完整链接
- **博主名字**: 发布该笔记的博主用户名
- **标题**: 笔记的标题
- **评论数**: 该笔记收到的评论数量
- **点赞数**: 该笔记收到的点赞数量
- **收藏数**: 该笔记被收藏的数量

## 注意事项

- 由于小红书网站的反爬虫机制，可能部分链接无法获取数据
- 如果遇到获取失败的情况，请稍后再试
- 请遵守网站的使用条款，不要过于频繁地请求数据
